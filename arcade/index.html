HOW TO PLAY

  1. PLUG YOUR MINICHORD INTO THE COMPUTER WITH A USB CABLE.
  2. OPEN A GAME IN CHROME, EDGE OR OPERA, WHICH CAN TALK TO MIDI INSTRUMENTS.
  3. PRESS CONNECT AND ALLOW MIDI. AFTER THAT, EVERY GAME CONNECTS BY ITSELF.

EACH GAME HAS A DEMO, A BEGINNER MODE THAT SHOWS WHAT TO PRESS, AND A HIGH-SCORE BOARD FOR MINICHORD PLAYERS. HARDER SETTINGS SCORE MORE. SOME EXTRAS (KNOB STEERING, KEY BARS, SLASH CHORD LEVELS) NEED THE UNOFFICIAL TEST-ALLFEATURES FIRMWARE; THE GAMES STILL PLAY WITHOUT IT.
